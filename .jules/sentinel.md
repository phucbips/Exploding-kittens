## 2024-05-18 - [CRITICAL] Open Firebase Realtime Database rules\n**Vulnerability:** Firebase database rules were set to `.read: true` and `.write: true` at the root level.\n**Learning:** This exposes the entire database to public read and write access, meaning anyone could download, modify, or delete all game data and potentially any user data present in the database.\n**Prevention:** Always default to restrictive rules (`.read: false`, `.write: false`) at the root and specifically grant access only to necessary paths (e.g., `rooms/`) using the principle of least privilege.
